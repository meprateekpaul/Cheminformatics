# Capstone Project Evaluation Rubric (Total: 20 Points / 100%)

| Criterion | Weight | Exemplary (90–100%) | Satisfactory (70–89%) | Needs Improvement (<70%) |
|---|---|---|---|---|
| **Data Quality & Curation** | 20% | Flawless curation pipeline: salts stripped, charges neutralized, duplicates aggregated with median + IQR checks, clear justification of activity thresholds, provenance logged. | Curation pipeline implemented but minor oversights (e.g., duplicate handling unstated or unverified threshold choice). | Raw data used without curation; duplicate SMILES unhandled; data leakage across splits. |
| **Modeling & Validation Rigor** | 30% | Rigorous Bemis-Murcko scaffold split; ≥3 diverse algorithms compared against naïve baselines; nested CV; appropriate metrics with confidence intervals (MCC, PR-AUC, ROC-AUC, R2, RMSE); no leakage. | Good cross-validation and multiple models; minor metric choices or random split instead of scaffold split. | Severe data leakage; only accuracy reported on imbalanced data; no baseline comparison. |
| **Interpretation & Domain** | 20% | Clear applicability domain definition (leverage/Williams plot); feature importance or SHAP values mapped back to chemical substructures; insightful error analysis of false positives/negatives. | Feature importance reported without mapping back to chemistry; applicability domain mentioned but not quantified. | Black-box model with zero interpretation or error analysis. |
| **Reproducibility & Code Quality** | 15% | Clean, modular code leveraging `chemlib`; fixed seeds; clear documentation; notebook executes from top to bottom without errors; conda environment fully specified. | Notebook executes with minor warnings; code mostly readable; seeds fixed. | Code fails to execute; missing dependencies; undocumented parameters. |
| **Scientific Communication** | 15% | Professional report following template; high-resolution publication-quality figures; insightful discussion connecting predictions to biological mechanism. | Well-written report; standard plots; adequate discussion. | Incomplete report; low-quality or unlabeled figures; superficial conclusions. |
